# Results and Testing

This folder contains the testing results and evaluation information for the Smart Sea Belt project.

## Testing Areas

The prototype is evaluated across the following areas:

- Heart-rate sensor operation
- Motion detection
- GPS location acquisition
- SOS button operation
- BLE communication
- LoRa communication
- Emergency alert generation
- Flotation deployment mechanism
- Rudder actuator mechanism
- Overall system communication
